## 走查中发现并修掉的问题

- 光滑几何上的"手作歪斜"是逐顶点随机位移，高分段曲面会皱成一团 → 改成按位置取低频噪声（同位置位移相同，不裂缝）。
- 情绪入口只能单选，也不认"安静 / 自然 / 简洁"这类日常说法 → 改成可多选、可输入，常用说法映射到情绪表，推荐按机制家族去重。
- 案例详情没有 SteamPeek 延伸 → 给 20 款上榜作品补抓 SteamPeek（`node scripts/cases/steampeek.mjs --charts`），详情页展示并标出库内作品的美术分组。
- 只能导出不能导入 → 导出对话框的"可复现配方 JSON"里加"导入配方"，逐项校验后恢复，可撤销。

## 仍需人工判断

- 截图对照只能证明"机制可实验"，不代表能复刻原作；案例拆解的技术判断都是"画面推断"。
- 运动中的稳定性（抖色、纸纹、线条抖动）需要在实际操作里看，静态截图看不出。

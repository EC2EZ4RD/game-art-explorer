# 技术补全与 2D / 2.5D 场景（2026-10-23）

用户原话（2026-10-23）：「1. 我记得之前有不少缺失的技术，导致表现不行？这个可以补上 2. 现在场景只有3D的，你也可以搭建一些2D 2.5D等等之类的场景」

## 起点

- 风格图谱 227 种风格里只有 43 种「没有缺项」；还没解决的缺项约 150 条（统计脚本在本地的 `qa/tech/`，不随仓库发布）。
- 配方卡上的「缺口」（`src/content/recipes.ts` 各配方的 `missing`）约 60 条。
- 大半缺项不需要素材，可以用程序实现：线条提按、雕刻线、点彩、木版套色、环境光照、次表面散射、清漆层、舞台聚光灯、线框几何、体素 AO、方块贴图、逐帧形变、带法线的像素精灵、属性冲突、伪 3D 道路、Mode 7、第一人称格子迷宫……
- 已有 2D 场景 17 个（横版 4、俯视瓦片 3、战棋 1、立绘 / 牌桌 7、白盒 2）。

## 共用的扩展点（主控 2026-10-23 先搭好）

- 后处理扩展：`src/engine/post/fx/registry.ts`（`registerFx`，8 个阶段，`medium` 阶段可以新增媒介取值）；Pipeline 在各阶段调用，不用改 Pipeline.ts。
- 参数：`src/dims/tech-*.ts`（`registerParams`；给已有选择型参数追加选项用 `extendOptions`）。
- 场景：`src/content/scenes25d/{iso,paper,retro}.ts`（元数据，`sceneRigValues` 在 `src/content/sceneRig.ts`）+ `src/engine/scene/scenes/{iso,paper,retro}.ts`（构建器）；新增 4 个场景类别：等距 2.5D、纸艺与剧场、伪 3D、竖版与节奏。
- `camera.tiltMode = 'depth'` 时 Pipeline 跳过屏幕带状移轴（P2 的按深度移轴接管）。

## 规则

- 第一批新参数默认关：现有配方、复刻、缩略图的画面一个像素都不变；第二批才让配方用上新技术并重烘缩略图。
- 本阶段不碰 Godot（不跑 check:godot / godot-validate）；只在网页侧测试与展示。
- 不下载、不安装、不调用 AI 生成。

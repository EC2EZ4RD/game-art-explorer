## 这一批的 UI 规律（喂给卡牌 / 竞速 / 射击布局与 M10 输入方式）

1. **卡牌游戏的 HUD 是"贴边整条"**（10 款里多是卡牌）：Balatro 左侧整条竖栏放盲注 / 分数 / 筹码 × 倍率大号像素数字；杀戮尖塔顶栏一条（血 / 金币 / 药水 / 遗物）+ 底部扇形手牌 + 左下能量球；Loop Hero 右侧整条装备栏 + 底部手牌。敌人意图（图标 + 数字）再次出现（杀戮尖塔、Alina of the Arena），和 R2① 的战术游戏一致。
2. **牌桌 / 卡册是叙事内容器**：Inscryption 的卡牌、天平计分、地图都是木屋桌上的实物；炉石收藏是一本皮面卡册；DICEOMANCER 卡组管理是一本摊开的书；Wingspan 是桌游数字版（米白纸卡 + 水彩插画 + 属性图标）。
3. **竞速 HUD 三件套**：速度（右下圆形表盘最常见：NIGHT-RUNNERS、Crashday、Slackers、极品飞车）、名次（左上超大数字：Garfield Kart 7/8、Circuit Superstars）、赛道进度 / 小地图（左侧竖条或左下 GPS 圆）。反重力竞速（Redout）不画速度表，用整屏速度线 + 镜头拉伸表达速度。
4. **射击 HUD 两角式**：左下血量（Half-Life 系列的橙色大数字、TF2 十字 + 数字、守望先锋的分段血块）、右下弹药；BioShock 系列与 DEATHLOOP 把 HUD 做成作品时代风格（装饰艺术圆框、60 年代拼贴海报）。VR（Half-Life: Alyx）与载具（Black Ops 座舱）则是叙事内。
5. **平台跳跃几乎零 HUD**：Ori、INSIDE、LIMBO、Neva、Rayman、Mirror's Edge 都是情境显现或全隐；例外是 Hollow Knight（左上灵魂罐 + 面具血量 + 线描卷草纹菜单）、Cuphead（左下扑克牌血量，1930 年代动画片头字）、BIT.TRIP RUNNER（顶部像素分数条）。
6. **手游（GameUI 18 款，竖屏 14 张卡）**：国风卡牌（忘川风华录、花亦山心之月、我自为道、炼仙传说）用书法竖排大字 + 屏风 / 卷轴；派对 / 休闲（蛋仔派对、上古王冠）是撞色圆角卡 + 斜切按钮；首充 / 福利海报大字价格（魔魔打勇士）。

## 取材的局限

- 3A 射击（BioShock、使命召唤、战地、远哭、神秘海域）与动作平台（瑞奇与叮当、双人成行、Ori）的商店图几乎都是宣传渲染，约 25 款按已知 HUD 记，置信度低。
- GameUI 手游依旧以开场 / 闪屏为主，竖屏在横排对照图里太小。

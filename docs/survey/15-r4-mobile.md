## 新增词表（喂给 M10）

R4 发现参数体系里缺"触屏操作长什么样"的词，补了 3 个参数（`ix` 组，生效条件：输入方式 = 触屏），参数总数 260 → 263：

| 参数 | 取值 | 这批的分布 |
|---|---|---|
| `ix.touchStick` 虚拟摇杆 | 无摇杆 / 固定 / 浮动 / 十字键 / 点地移动 / 滑动手势 | 无 18、点地 4、滑动 2、固定 2、浮动 2、十字键 1 |
| `ix.touchCluster` 触屏按钮布局 | 大键 + 弧形环绕 / 技能方格 / 底部一排 / 按住展开轮盘 / 左右两个大键 | 底部一排 8、大键 + 弧形 5、两个大键 1 |
| `ix.thumbZone` 握持与拇指区 | 横屏双拇指 / 竖屏单手 / 平板桌面 | 竖屏单手 21、横屏双拇指 6 |

## 规律

1. **国内手游的"战斗界面"多半没有摇杆**（18 / 39）：自动战斗 + 倍速 / 托管 / 跳过按钮（梦想指针、小虾米战三国、战神之决），玩家只在底部一排英雄头像上点大招。→ M10 的触屏布局要有"无摇杆、只有底部头像条 + 倍速键"这一型，而不是默认摇杆 + 技能。
2. **有摇杆的是 ARPG / MMO / 派对**：右下一个大攻击键 + 技能沿四分之一圆弧（天涯明月刀、三界天骄、暖雪），左边固定或浮动摇杆；MMO 在技能键上还标了键位字母（同一套 UI 兼容手柄 / 键鼠）。
3. **竖屏 = 单手**：所有竖屏样本都把主按钮、页签、确认放在下 1/3（Royal Match 的 Level 大按钮、阿尔米娅赞歌的"挑战"、苏打世界的 PLAY），顶部只有资源与标题；两侧竖排活动入口（带红点和倒计时）是 F2P 主界面的标配（7 款）。
4. **消除 / 合成类**：棋盘占下 2/3，对战信息（比分胶囊、双方头像）压在顶部；道具按钮在底部角落。
5. **触控尺寸**：样本里的主按钮都明显大于技能键，倍速 / 暂停等次要键偏小（约 36–44pt），和 M8b 的触控检查（ix.touchSize 默认手机 88px@1080p ≈ 44pt）一致。

## 局限

- 没有 ADA / Google Play 年度最佳的名单与截图；这批全部是 GameUI 上的国内手游，偏 F2P 与自动战斗，西方付费手游（Monument Valley、Alto、Sky 之类）的触屏 UI 只在 R2③ 里有零星几张。下次可以把 ADA 游戏类获奖名单手工列出、用商店截图补。
- 每款只看了一张图，触屏布局的编码（尤其浮动摇杆——静态截图里看不到底盘）有推断成分。

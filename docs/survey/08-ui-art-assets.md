# 08 · UI 美术资产与社区参考（GameUI.net + Interface In Game）

> 2026-10-14。用户补充："很多 UI / HUD 是有美术资产的"，并给了两个参考站。本篇回答三件事：UI 里到底有哪些美术资产、它们出现在哪些界面、对探索台的计划意味着什么。
> 数据全部由脚本收集与统计（不经过模型），本文只读统计摘要和 4 张材质对照图。

## 2. 发现

### 2.1 美术资产集中在"卖东西、给奖励、讲故事"的界面，局内 HUD 很少用

GameUI 的截图带"材质"标签的一共 3,995 张（全站 161 万张里约 0.25%，打标很稀疏，所以只看相对分布）。按界面看：

- 带材质标签的截图最常出现在：商城、充值、恭喜获得、福利、通行证、招募、转盘 / 抽奖、过场动画、登录界面、Loading、图鉴、关卡选择。
- 反过来抽样每种界面 100 张：**战斗界面（局内 HUD）只有 1 张带材质**；菜单 22 张（其中纸张 12）、建造 / 家园 9、拍卖行 9、登录 6、宝箱 / 金币 6、首充 5。

结论：局内 HUD 讲究"轻"和"清楚"，大多是程序化的形状、图标与数字；**贴图、装饰、实物化的 UI 主要用在菜单、商城、奖励、标题、读取、图鉴这些"停下来看"的界面**。这和我们的 M9（界面场景）直接相关——资产皮肤的价值主要在 M9，而不是 M1 的 HUD 样本。

### 2.2 "材质"其实是四类不同的东西

看了 32 种材质各 3 张样例（`qa/refs-cache/gameui/sheet-materials-1..4.jpg`）后，GameUI 的"材质"标签混了四类：

1. **面板底材**：木板、纸张 / 羊皮纸、布（幕布、旗面）、石、皮革、玉 / 瓷、磨砂玻璃、塑料。做法是可平铺的材质贴图 + 九宫格边框。
2. **道具与货币美术**：标"金属"的多半是金币、宝箱，标"水晶 / 玻璃"的多半是宝石货币和礼包图标——是图标 / 插画，不是面板。
3. **叙事内物件（整屏做成场景里的东西）**：书籍（图鉴做成书架）、卷轴（任务、地图做成展开的卷轴）、台子 / 桌面（菜单做成书桌、牌桌）、旗帜（排行、活动做成挂旗）、"场景化"（商店做成柜台）。
4. **表面处理与特效**：代码 / 发光、镭射、光影、魔法阵（抽卡、胜负的背景）、花瓣 / 樱花、云纹、笔触 / 做旧、水墨、钢笔 / 铅笔、几何切割、条纹、背景平铺、半色调、海报式构图。

数量上，第 3 类最大：书籍 481、场景化 392、卷轴 210、台子 / 桌面 186，合计超过除纸张（1,299）以外所有面板底材的总和。**"把 UI 做成场景里的物件"是资产型 UI 最常见的做法**，对应我们第 2 维"UI 放在哪"里的"叙事内"。

### 2.4 设计师社区在意什么（评论）

高赞作品下 ≥ 12 字的评论 262 条。关键词频次：风格 29、动效 15、AI 14、图标 8、统一 8、颜色 6、氛围 6、交互 6、信息 5、质感 4。反复出现的批评（意译）：

- 主次层级不清、功能文字看不清——"像原画作品集，不像 UI"；"只为视觉服务，忽略了 UI 的本质"。→ M8 可读性检查（对比度、最小字号、层级）。
- 风格混搭没有主次（有人建议"赛博 70%、二次元 20%、国潮 10%"这样定比例）；材质与世界观不符（"装订皮革不像北欧"）。→ 第 5 维"UI 跟随画面"：材质要从世界观里来。
- 被夸的是"角色、场景、UI 高度统一"。→ 同上。

### 3.1 材质截图逐张归纳（GameUI，29 种材质、约 1,100 格）

`qa/refs-cache/sheets/gameui-materials/` 的 44 张对照图（每种材质最多 48 格）由 10 个子代理逐张看过，归纳出 160 种"做法"，结果在 `docs/survey/data/ui-asset-materials.json`。

- **站方材质标签噪声不小**：平均约 18% 的格子看不出该材质；卷轴 / 旗帜约 40%（书、红旗、木框混标），云纹 55%。统计时只能看相对趋势。
- **做法按层分布**：叙事内物件 A3 37 种、表面处理 / 特效 A4 34、面板底材 A1 19、插画 A7 18、边框饰件 A2 17、图标 A5 16、标题字 A6 6。
- **按复现方式**：程序化 32、叙事内场景 24、九宫格 23、插画 23、图标图集 16、序列帧 16、**可平铺材质贴图只有 7**、字体 6。→ "换一张材质贴图"不是资产型 UI 的主体；**九宫格边框、叠加特效层、场景容器、图标集**才是。
- **最常见的做法**（按格数）：人物主视觉整屏插画（海报）；整屏房间 / 桌面、物件即入口（场景化）；木桌框 + 金属角饰；金端卷杆的纸面挂轴（可纵向拉长）；米白纸卡嵌进深一档米褐面板（层级靠明度差、不靠描边）；金币堆 / 宝石的档位阶梯图标；水墨整屏插画；宣纸浮层 + 破边墨渍；放射光芒 / 光柱；角色身后的发光法阵；开书 / 光爆动效。
- **各代理不约而同的结论——皮肤应拆成可独立替换的槽位**，而不是"一种材质"：
  1. **外框**（木 / 石 / 金属 / 玉 / 科技线框，九宫格）
  2. **内芯**（米白纸、纯色或半透明；层级靠"底色 + 深一档内嵌色"的明度差）
  3. **饰件槽**：页签（菱形、木牌）、标题牌（云形、卷轴头、书法 + 印章）、角花、徽章底座（底座材质 + 通用符号两层）
  4. **叠加特效层**：发光 / 镭射 / 光柱 / 魔法阵 / 花瓣粒子 / 颗粒噪点，加色混合、跟随主题色，和面板材质解耦
  5. **场景容器**：书（左页 / 书脊 / 右页）、卷轴（卷杆 + 可拉长纸面）、挂旗（顶帽 + 可平铺中段 + 尖底）、书桌、柜台、手机——同一份菜单数据换壳
  6. **图标集**：货币三档（单个 / 一堆 / 一箱）、道具、系统功能
- 材质与皮肤的对应修正：**水晶 / 玻璃、金属多半指货币图标**，不是面板；玻璃面板只需要毛玻璃参数（模糊 + 半透明 + 1px 亮边），已有；**布料是幕布 / 挂旗场景**，不进面板材质选项；**纸是最通用的内芯**（弹窗、卷轴、书页、地图四种外形共用）。

### 3.2 Interface In Game 人工浏览（34 款）

按条款不爬取，只在浏览器里逐页查看 34 款（策略 / 建造 9、动作 / 探索 / RPG 13、养成 / 解谜 / 叙事 6、卡牌 / 竞速 / 射击 6），记录每款的界面元素计数、界面名称与观察，笔记里不存图片：`docs/survey/data/iig-browse-notes.json`。

- **每款都有的界面**：局内（34/34）、菜单（34）、设置（34）、叠加弹层（33）、读取（29）、进度 / 成就（26）、教程（26）、背包（25）、属性（25）、角色（24）、制作人员（24）、地图（23）、对话（22）。技能树（11）、记分板（3）、大厅（2）是品类专属。
- **菜单常被"叙事化命名"**：Hades 的技能树叫 Mirror of Night、商店是 Well of Charon；Frostpunk 的法典 Book of Laws 是一整屏星图；Elden Ring 的赐福点菜单；动森的菜单就是 Nookphone；MGSV 的 iDroid；旷野之息的希卡石板。→ 叙事内 UI 不只是 HUD 的事，**菜单的"壳"就是 3.1 的场景容器**。
- **同一类界面在不同品类里差别很大**：策略 / 建造多"信息叠层 + 树状图"（Civ 的科技 / 市政树、Anno 的城市吸引力叠层、Cities 的里程碑与信息视图、XCOM 的士兵属性）；卡牌多"开包、合成、赛季宝箱、段位"；竞速多"车库展示、追捕过场、前端大厅"；射击多"大厅、记分板、开箱、集结队伍"。这些可直接用作 M7 / M9 的品类布局清单。

| 瑞士几何 / 极简表格 | Control、Mini Metro、MGSV 结算 | 发丝线网格、斜线阴影、超大粗体字、单色 | 纯程序 | 已有瑞士 / 终端，加斜线图案即可 |
| 全息空间 | Detroit、Cyberpunk、MGSV iDroid、XCOM | 线框网格贴在场景里、带透视的倾斜面板、色差故障 | 空间内放置 + A4 | 有"科幻"，缺空间内透视与故障 |
| 倾斜动感 / 漫画 | Overwatch、Hi-Fi Rush、No Man's Sky、NFS Heat | 平行四边形面板、斜体数字、网点、锯齿对话框、拟声字 | A4 网点 / 斜线 | 有"漫画""构成主义"（已支持倾斜） |
| 圆润友好 | 动森、旷野之息、Stardew（像素木框） | 圆胖气泡 + 药丸名牌、图案平铺底、像素木框 | A1 图案 / 木 | 有"扁平""像素"，缺图案底、像素木框 |
| 叙事内设备 / 容器 | 动森手机、MGSV iDroid、希卡石板、RDR2 手持地图、Hearthstone 木箱与收藏册、Florence 货架 | 菜单就是世界里的东西 | A3 | **缺**，对应 3.1 的"场景容器" |

- **跨游戏的共同点**：
  - HUD 克制、菜单厚重。Hades、Hollow Knight、Elden Ring、Clair Obscur 的局内只有几条细条和图标，装饰都留给菜单，和 GameUI 的统计（资产集中在停下来看的界面）一致。
  - 倾斜（平行四边形）是动作 / 竞速 / 射击的通用语汇。
  - 空间内 UI（头顶图标、瞄准框、AR 面板）在策略、射击、科幻里都很常见。

### 3.3 GameUI 设计师作品（收藏 × 2 + 点赞 × 3 排名前 60）

60 个作品共 756 张图，下载缩略图后拼成对照图逐个看过（`qa/refs-cache/sheets/gameui-works/pair-01..10.jpg`）。最受欢迎的几个：Link Tape（赞 718、藏 706，复古波普卡带收藏）、致敬《紫罗兰永恒花园》（613 / 520，打字机信件叙事内）、欧美卡通魔幻（468 / 676，彩绘重装饰）、末班车（473 / 428，恐怖霓虹）、解神者赛季 UI（265 / 500）。

- **几乎每个高分作品都是同一套流程**：世界观 → 关键词 → 情绪板 / 参考 → 色彩构成（不少作品把"场景色"和"控件色"分开列）→ 字体（标题字 + 正文字）→ LOGO → 主界面 → 系统界面 → 图标 → 动效（60 个全部带视频）。
  - → 皮肤的数据结构可以照这个顺序组织：关键词、色板（场景 / 控件两组）、字体对、标题字处理、材质槽位、图标风格、动效。
  - → 描述导出也照这个顺序写，正好是美术外包能接的规格书。
- **标题字 / LOGO 是独立的大件（A6）**，比计划里分量重得多：
  - 国风作品几乎都有书法标题（九黎、山海、风起洛阳、琅轩灵御录、射雕、神话篇）
  - 欧美卡通是 3D 立体卡通字（Hidden Leaders、GOD of ANGULA、Rise of Cultures）
  - 科幻是细线宽字距（DUNE、FOUNDATION、星云），恐怖是窄体粗字（末班车）
  - → A6 应该成为一个独立维度"标题字处理"，选项：书法、立体卡通字、细线宽字距、手写、哥特黑体、窄体粗字
- **关键词 → 材质**的映射是设计师显式做的：GOD of ANGULA 把"原始"拆成牛皮纸、石头、木头、布；Jewels 用金币、金箔、花丝做情绪板；Epic of Tiara 写明"轻与重的结合"（Diablo 的厚重 + 扁平的轻）。→ 探索台可以加一个"关键词 → 资产槽位默认值"的规则表。
- **同一布局换色板**：Valorborn 的六边形主界面出了红、紫、蓝三套配色；不少作品给"场景色 / 控件色"两组色块。→ 印证"UI 取色自色板"的做法，并提示控件色板应独立于场景色板。
- **AI 出图标已经是常规做法**：2024 用 Midjourney 生成游戏图标的作品对比了工期——手绘 1–3 天、建模渲染 3–7 天、AI 几分钟。→ M11 用 AI 批量生成图标集是合理的。
- 风格分布（60 个里）：暗黑写实 / 金色花丝细线最多，其次是国风水墨书法、二次元科幻、卡通 3D / Q 版、复古波普 / 扁平、街头贴纸、黑色电影 / 恐怖。

### 3.4 GameUI 热门游戏（社区热度前 100，每款取 48 张，共 4,800 张）

看了前 24 款（每款前 6 张，`qa/refs-cache/sheets/gameui-games-top24/`）。站方的截图按玩家流程排序，前几张几乎都是"进游戏"那一段：厂商闪屏 → 标题（大 LOGO + 主视觉插画）→ 公告 → 选服 → 创角 / 捏脸 → 新手引导。

- **标题屏 = 标题字 + 主视觉**：书法（永劫无间、人定胜天、百闻牌、忘川风华录）、立体卡通字（艾尔多战记、蛋仔派对、圣树唤歌、无限王国），又一次印证 A6 的分量。
- **公告和选服是资产化最明显的"系统弹窗"**：国风用宣纸 + 红印；欧美用羊皮纸卷轴 + 木框；Q 版用圆角糖果色面板；二次元用白色细线卡片。和 3.1 的"外框 + 内芯 + 饰件"完全一致。
- 这正好对应新增的界面类型 `screen.frontend`（登录 / 选服 / 创角）；局内 HUD 要看每款后面的截图，R2 建卡时按 `function-samples` 的功能标签挑，不按顺序取。
- 其余 76 款与 Steam 上的 292 款 Interface In Game 游戏（1,724 张商店截图，`qa/refs-cache/sheets/steam-iig/`）已经下载拼好对照图，留给 R2 建卡时按品类逐批看，这次没有全部过目（节省 token）。

## 4. 对计划的影响（2026-10-14 用户已批准，已写入 docs/ui-hud-plan.md）

1. **内容分类已更新**（已完成）：`src/content/uiContent.ts` 新增 7 种界面——主界面 / 大厅、登录 / 选服 / 创角、匹配 / 组队、社交、排行 / 赛季、运营活动（签到、抽卡、通行证、充值、拍脸图）、关卡 / 章节选择，共 26 种界面 + 18 种信息元素；GameUI 的 68 个功能标签、Interface In Game 的 21 个元素标签都对上了我们的分类（`check:content` 校验全覆盖）。
2. **新增里程碑"资产皮肤"**（放在 M3 之后、M4 之前）：按 3.1 的结论把皮肤拆成 6 个可独立替换的槽位——外框（九宫格）、内芯（底色 + 内嵌色）、饰件（页签、标题牌、角花、徽章底座）、叠加特效层（发光 / 镭射 / 法阵 / 粒子 / 颗粒，加色混合跟随主题色）、场景容器（书 / 卷轴 / 挂旗 / 书桌 / 柜台 / 手机）、图标集（货币三档等）；绘制器加九宫格与平铺；先用**现成素材和程序化处理**做第一批（不需要生成）：纸 / 羊皮纸面板、绢本、剪纸云纹边、笔触做旧边、半色调 / 条纹 / 平铺背景、镭射、发光、魔法阵。
3. **M4 Godot 导出**增加 `StyleBoxTexture` / `NinePatchRect` / `TextureProgressBar`。
4. **M9 界面场景**优先做资产最重的几屏：商城、奖励弹窗、标题、读取、图鉴（叙事内的书 / 卷轴 / 书桌是一种布局变体）。
5. **M11 AI 生成 UI 资产提前**到"资产皮肤"之后，按逐张清单批准后再生成：6 种面板底材（木、石、皮革、玉、金属、羊皮纸）、5 套边框（欧美金框、纹章、国风云纹、二次元科技、Q版糖果）、4 套图标（每套 16 个，一张出一套）、书 / 卷轴 / 书桌 3 张叙事内底图。
6. **R2 建卡**：每张卡增加"资产"字段（A1–A7 用了哪些）、GameUI / Interface In Game 链接；GameUI 社区热门游戏作为 R4（手机）的候选来源。
7. **新皮肤家族**（3.2 的 10 个家族里探索台还缺的）：线描花饰、细线几何、全息空间（透视 + 故障）、圆润图案、像素木框、重装饰雕花框（要素材）、叙事内设备 / 容器（要场景容器槽）。前五个可以纯程序绘制，放进 M3 的"12 种新皮肤"。
8. **标题字处理成为独立维度**（3.3）：书法、立体卡通字、细线宽字距、手写、哥特黑体、窄体粗字；书法和立体字需要字体或生成素材，其余靠 M2 的字体 + 程序描边 / 投影 / 字距。
9. **皮肤规格按设计师流程组织**（3.3）：关键词 → 色板（场景色 / 控件色两组）→ 字体对 → 标题字 → 材质槽位 → 图标风格 → 动效；描述导出照这个顺序输出，可以直接当外包规格书。

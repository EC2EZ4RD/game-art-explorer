## 这个品类的 UI 规律（喂给 M7 品类布局与 M9 界面模板）

1. **"零 HUD / 情境显现"是 3A 探索作的主流**：情境显现 14、电影模式（全隐）9，常驻只有 1（艾尔登法环）；信息密度极简 23 + 稀疏 33，占六成。GRIS、Journey、Hellblade、Firewatch、Dear Esther、Riven、ABZU 都没有 HUD——信息改由世界承担（围巾长度 = 飞行能量、手臂黑纹 = 腐化、手里的纸地图）。→ `rel.hudVisibility` 与 `cnt.density` 是这个品类的第一旋钮，叙事内（diegetic）10 款也主要出在这里。
2. **血条位置两派**：左上 15（魂系、巫师、Hi-Fi Rush、旷野之息）vs 左下 13（黑神话、Lies of P、战神、Hades）。条形以普通横条 14、细条 8 为主，分段格 5（像素 / 动作），心形图标列 2（塞尔达、Eastward）；弧形 / 圆环 / 血球各 1（王国之心、荒野大镖客 2、暗黑 4）。
3. **技能栏**右下最多（9），其次左下 / 下中（各 4）；技能格 12、物品快捷栏 6（魂系十字四格）、大招充能 4（战神、FF7R）。
4. **Boss 血条压在底部中央带名字**（魂系、黑神话、Lies of P）或顶部（FF16）——和 M7 魂类布局一致。
5. **小地图**：平面小地图 15，罗盘条 6（天际、刺客奥德赛、霍格沃茨、地平线、艾尔登法环），圆环雷达 2；位置左下 7 最多（刺客系列、荒野大镖客）。
6. **对话框**：带尾气泡 9（JRPG、像素、漫画风）、底部通栏 4、无框字幕 2、聊天软件式 1（The Artful Escape 右侧堆叠黑气泡）。
7. **标题字体**：衬线 10（魂系、巫师、Octopath）、书法 5（黑神话、对马岛、逆水寒）、哥特黑体 / 窄体 / 涂鸦各 3；动作游戏的"评价字 / 拟声字"（DMC 风格字母、Hi-Fi Rush 整屏漫画拟声字、手游 BOOM）是一类独立的反馈元素。
8. **整合底座**：博德之门 3、暗黑 4、暗黑地牢 1/2——RPG 里"下半屏一整条"仍是主流（暗黑地牢把英雄卡、技能、地牢地图放进石雕底座，和插画同一画风）。
9. **把整屏变成叙事内容器**：RPG Time（整屏是书桌 + 作业本 + 手工卡纸，`画在玩法区外的边框里`）、Knights And Bikes（旧照片暗角 + 贴纸）、刺客信条（整个 HUD 是 Animus 机器的界面，元 UI）。
10. **手游（GameUI 16 款）**：竖屏 8；国风 MMO（逆水寒）宣纸面板 + 竹叶灯笼角饰 + 书法标题；二次元（原神、星穹铁道、剑与远征启程）米白 / 深色圆角卡 + 细线；休闲（贪吃怪、几何王国）所有弹窗是米白圆角卡 + 底部橙色关闭叉；活动页用超大涂鸦字（超时空跑跑）。

## 取材的局限

- **3A 的 Steam 商店图几乎全是宣传渲染**：战神、刺客信条全系列、蜘蛛侠、地平线、霍格沃茨、星战、FF7R 等约 35 款的商店图里没有 UI，这些卡按该作已知 HUD 记（笔记里写了"商店图无 UI"），置信度低于看得见 UI 的卡。下一批（R2③④）这类游戏优先从 GameUI / Interface In Game 补原图。
- GameUI 的"按功能标签取"在这批仍常拿到开场动画 / 闪屏（黑暗之潮、绝区零、超时空跑跑）；接口慢且偶尔超时（2 款失败）。
- 竖屏手游在横排对照图里很小，竖屏单独拼图仍待做。

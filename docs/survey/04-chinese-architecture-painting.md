# 中国建筑语法与中国画渲染参考（Chinese Architecture & Painting Reference）

这份文档有两个用途：一是让探索台搭出**有文化依据**的中式场景（屋顶、斗拱、台基、门窗、院落、园林、地域差异、色彩），二是让它跑**中国画风格渲染实验**（线描、皴法、设色、构图、墨色），并为每项技法标注实时 3D 能做到什么程度。

## 0. 速查：做一个"像样的中式建筑"最少要对的 10 件事

1. **三段式**：台基、屋身（柱与墙）、屋顶。屋顶在立面上通常占很大比例，宋代殿阁尤其显著，是第一识别特征。
2. **屋面是凹曲面**，不是平面斜坡。坡度从屋檐到屋脊逐步变陡（举折/举架，见 1.3）。
3. **屋檐要深**：出檐加飞椽伸出柱外很远，檐下形成浓重阴影带。
4. **翼角起翘**：转角处的屋檐在平面上向外伸（生出），在立面上向上翘（起翘）。北方官式含蓄，江南、闽粤夸张。
5. **开间是奇数**：明间居中最宽，向两侧递减，建筑沿中轴对称。
6. **屋顶形式有等级**：重檐庑殿最高，硬山最低（1.2），皇宫用黄琉璃瓦。乱用等级会显得"不对"。
7. **斗拱只出现在高等级建筑**（宫殿、寺庙、衙署），普通民居基本不用，这一点按史实处理（[14] 正文有一条带"需要引用"标记的说法，称唐以后斗拱为皇家专属，不能直接当结论）。
8. **木构上漆，梁枋上彩画**：北方官式是"檐下青绿、柱身朱红"，江南民居多为栗色木构、白墙、黑瓦。
9. **院落是基本单位**：建筑很少孤立存在，总是围合成院、成群、成轴线。
10. **地域差异大于朝代差异**（对游戏而言）：北京四合院、苏州园林、徽州、闽南红砖、客家土楼、陕北窑洞，一眼就能分辨，不要混搭。

## 1. 建筑语法（Building grammar）

### 1.1 单体的三段式与构架

- **台基（platform）**：用夯土、砖或石做成的基座，高等级建筑用**须弥座**（Sumeru pedestal），见 1.6。
- **屋身（body）**：柱网加墙。墙只起围护作用、不承重，这是**抬梁式**（post-and-lintel，北方与官式主流）的特点：沿进深方向成排立柱，柱顶架梁，梁上叠短柱和短梁 [34]。**穿斗式**（chuandou，南方民居常见）的柱更密，直接承檩，用穿枋串联。
- **屋顶（roof）**：靠檩、椽、望板和瓦构成。曲面形状由举折（宋）或举架（清）决定。

> 建模提示：一套模块化资产（modular kit）的最小集合是：台基块、柱、额枋（柱顶横梁带）、斗拱带、墙或隔扇片、屋顶曲面、正脊、垂脊/戗脊、吻兽/脊兽。

### 1.2 屋顶类型（Roof types）

清代屋顶等级由高到低为：重檐庑殿、重檐歇山、单檐庑殿、单檐歇山、攒尖、悬山、硬山 [6]。卷棚、盝顶、盔顶、十字脊属于"次要形式"[6]。

| 类型 | 别名（宋 / 清 / 日） | 形体描述 | 等级与典型用途 | 几何构造配方（primitive recipe） | 实例 |
|---|---|---|---|---|---|
| **庑殿顶** Hip roof | 四阿顶、五脊殿、吴殿 / 庑殿 / 寄棟造 | 四面坡，1 条正脊 + 4 条垂脊共五脊；前后两面是梯形，左右两面是三角形；**两侧没有山墙** [7] | 最高等级，重檐庑殿用于最重要的殿堂（如太和殿） | **高度场法**：平面矩形半宽 a（面阔方向）、半深 b（进深方向），任意点到最近檐边的距离 d = min(a−\|x\|, b−\|z\|)，屋面高 h = P(d)，P 是举折剖面曲线（1.3）。正脊长 = 2(a−b)。**推山**（清式，把正脊加长，使垂脊在俯视中弯曲 [7]）：先把 x 距离乘以系数 k<1 再取 min | 太和殿（重檐）|

### 1.3 屋面曲线：举折（宋）与举架（清）、出檐、起翘

**宋式举折**（《营造法式》卷五原文 [2]）：

- **举屋之法（总高）**：殿阁楼台，把前后橑檐方心的距离 D 分成 3 份，从橑檐方背到脊槫背举起 1 份，即 **H = D/3**。甋瓦厅堂取 **H = D/4 × 1.08**（"四分中举起一分，又……每一尺加八分"）；甋瓦廊屋和瓪瓦厅堂取 **D/4 × 1.05**；瓪瓦廊屋取 **D/4 × 1.03**；副阶、缠腰取 D/2 中举起 1 份。
- **折屋之法（曲线）**："以举高尺丈每尺折一寸，每架自上递减半为法"。做法是从脊槫背拉直线到橑檐方背，在第一缝处下折 **H/10**；再从第一缝拉直线到橑檐方背，在第二缝处下折 **H/20**；以后每缝减半 [2][5]。
- 宋式是先定总高、再从上往下折出曲线；清式是"举"和"折"同时、从下往上推 [5]。

```js
// 宋式举折 → 返回各槫（檩）高度。n = 每坡椽数（架数），D = 前后橑檐方距离
function songJuZhe(D, n, kind = 'dian') {
  const H = kind === 'dian' ? D / 3 : (D / 4) * 1.08;        // 殿阁 / 甋瓦厅堂
  const half = D / 2, xs = [...Array(n + 1)].map((_, i) => (half * i) / n); // 0 = 脊，n = 檐
  const ys = new Array(n + 1); ys[0] = H; ys[n] = 0;
  let drop = H / 10;
  for (let k = 1; k < n; k++) {
    const t = (xs[k] - xs[k - 1]) / (half - xs[k - 1]);       // 从上一缝到檐口的直线
    ys[k] = ys[k - 1] * (1 - t) - drop;                         // 直线高度再下折
    drop /= 2;
  }
  return xs.map((x, i) => [x, ys[i]]);                          // 用样条（Catmull-Rom）连接成 P(d)
}
```

**清式举架**（常见引述，**未核实**原书逐字）：从檐步往上，每一步架的高跨比依次增大。常见取值是檐步"五举"（0.5），脊步"九举"（0.9）。七檩房大致为五举、七举、九举；九檩房大致为五举、六五举、七五举、九举。递推方式是 y += 步架 × 举数，从檐口算到屋脊。清式屋面通常比宋式陡，这与 [8] 所述"明代以来屋坡举折愈来愈陡峭高耸"一致。

**出檐与飞椽**（宋，[2]）："造檐之制，皆从橑檐方心出。如椽径三寸，即檐出三尺五寸；椽径五寸，即檐出四尺至四尺五寸。檐外别加飞檐，每檐一尺，出飞子六寸。"换算后：檐出约为椽径的 8–12 倍，**飞子再伸出檐出的 0.6 倍**。

**生出与生起**（宋，[2]）：
- **生出**：檐口在平面上从次角柱向角梁逐渐向外伸。一间生 4 寸，三间生 5 寸，五间生 7 寸。
- **生起**：角柱比平柱高。三间生高 2 寸，五间 4 寸，七间 6 寸，九间 8 寸，十一间 1 尺，十三间 1.2 尺，"令势圜和"。
- **侧脚**：柱首向内微收，正面每 1 尺柱高收 1 分（1%），侧面收 8 厘（0.8%）。

> **经验值（建模起点，非文献）**：
> - 总出檐（檐椽加飞椽，水平量）≈ 0.35–0.45 × 檐柱高（北方官式）；江南厅堂约 0.25–0.35。
> - 翼角起翘用一条沿檐口的参数曲线表示：s ∈ [0,1] 从翼角起点到角梁尖，竖直抬升 Δy = R·s²，平面外伸 Δh = F·s²。北方官式 R ≈ 0.2–0.35 × 出檐、F ≈ 0.1–0.2 × 出檐；江南"发戗"可到 R ≈ 0.8–1.5 × 出檐。
> - 清式口诀"**冲三翘四**"：仔角梁在平面上比正身檐椽多冲出 3 个椽径，在立面上翘起 4 个椽径（**未核实**）。
> - 江南《营造法原》（姚承祖）的嫩戗发戗、水戗发戗做法起翘更大，具体数值**未核实**。

### 1.4 模数：宋"材分°"与清"斗口"

**宋：以材为祖**。"凡构屋之制，皆以材为祖。材有八等，度屋之大小因而用之。"材的断面高（广）15 分°、宽（厚）10 分°，即 3:2。栔高 6 分°、宽 4 分°；材上加栔称为"足材"（21 分°）[1][4]。

| 等级 | 广 × 厚（寸） | 1 分° = | 用于 [1] |
|---|---|---|---|
| 一等 | 9 × 6 | 0.6 寸 | 殿身九至十一间 |
| 二等 | 8.25 × 5.5 | 0.55 寸 | 殿身五至七间 |
| 三等 | 7.5 × 5 | 0.5 寸 | 殿身三至五间，或厅堂七间 |
| 四等 | 7.2 × 4.8 | 0.48 寸 | 殿三间，厅堂五间 |
| 五等 | 6.6 × 4.4 | 0.44 寸 | 殿小三间，厅堂大三间 |
| 六等 | 6 × 4 | 0.4 寸 | 亭榭或小厅堂 |
| 七等 | 5.25 × 3.5 | 0.35 寸 | 小殿及亭榭 |
| 八等 | 4.5 × 3 | 0.3 寸 | 殿内藻井，或施铺作多的小亭榭 |

常用构件的分°值 [1][4]：华栱（两卷头）长 72 分°，令栱 72，慢栱 92，瓜子栱 62，栌斗 32（在角柱上为 36）；每跳长不超过 30 分°，多跳合计不超过 150 分°。柱径：殿阁两材两栔至三材，厅堂两材一栔，余屋一材一栔至两材 [2]。

**清：斗口制**（雍正十二年即 1734 年颁布的《工程做法》[16]；梁思成整理为《清式营造则例》[17]）。斗口指平身科坐斗的卯口宽，是清式基本度量单位。坐斗长、宽各 3 斗口，高 2 斗口；正心瓜栱长 6.2 斗口、高 2、宽 1.25；两攒斗栱间距 10–12 斗口 [15]。斗口分 11 等（1 寸至 6 寸，每级 0.5 寸）是常见说法，**未核实**。小式（不用斗拱）建筑常引的比例是明间面阔 : 檐柱高 ≈ 10 : 8、檐柱径 ≈ 柱高的 1/11（**未核实**）。

> **工具落地**：全场景只设一个模数 `m`（材高或斗口），所有构件用 `m` 的倍数定义。切换"一等殿 / 六等亭"只需改 `m`，比例自动正确，这正是材分制的初衷（[4]："一套图样可用于一等材构件，也可以按比例缩小"）。

### 1.5 斗拱的简化层级（Dougong LOD ladder）

斗拱按位置分为柱头科（宋：柱头铺作）、平身科（补间铺作）、角科（转角铺作）[14]。从唐到清，斗拱排布由疏到密、相对柱高由大变小，结构作用减弱、装饰作用增强 [14]。

| LOD | 形式 | 构成 | 用途 | 实现 |
|---|---|---|---|---|
| L0 | 完整铺作（如七铺作双杪双下昂，佛光寺东大殿 [14]） | 栌斗 + 华栱（出跳）+ 泥道栱 + 瓜子栱、慢栱、令栱 + 下昂 + 耍头 | 近景主殿 | 程序化拼装，30–60 个小盒子，用实例化（instancing）【实】 |
| L1 | 一斗三升 / 斗口跳 | 一个大斗 + 一根横栱 + 三个小斗 | 中景、偏殿 | 1 个合并网格，实例化 |
| L2 | 把头绞项作、单斗只替 | 柱头一个斗加替木 | 廊、门屋 | 简单盒子 |
| L3 | "铺作层"挤出带 | 檐下一条阶梯形截面的挤出体，加法线贴图模拟分攒 | 远景 | 挤出 + 法线【实】 |
| L4 | 彩画贴图带 | 平面贴图 | 极远景、UI | 贴图【材:斗拱彩画条】 |

- **转角**：角科沿 45° 对角线出斜栱和斜昂，是程序化最容易出错的地方。可以先做"两向正交的柱头科 + 一根 45° 斜栱"来近似。
- **南方变体**：江南、闽粤常用插栱、撑栱、牛腿（斜撑木雕），代替层叠斗拱。如意斗拱是辽、五代斜栱发展出的网状结构 [14]。
- **雀替**：梁枋与柱相交处的短木，北方官式实心、可承力，闽南的"插角"多透雕、纯装饰 [32]。它是一个低成本、高识别度的模块。

### 1.6 台基（Platform）

- **普通台基**：砖石包砌的矩形体，四周有阶条石，前后出踏跺（台阶）。
- **须弥座**：佛座演变而来的叠涩线脚，自上而下大致为上枋、上枭、束腰、下枭、下枋、圭角。可以用一条剖面曲线绕矩形挤出（profile sweep）【实】。
- **月台、御路、栏杆**：月台是殿前的扩展平台；御路是踏跺正中的雕龙斜石；栏杆由望柱和栏板组成，是实例化的好对象。
- **比例**：台基高度随建筑等级提高。清式小式台明高约为檐柱高的 1/5（常见引述，**未核实**）。太和殿用三层须弥座。
- **影壁**：有一字、雁翅（八字）、撇山等形式，由座、身、顶三段组成，壁心多用 45° 斜放的方砖 [23]，是院落入口的标志性道具。

### 1.7 柱网与开间（Column grid & bays）

- **面阔**按开间数计，取奇数（1、3、5、7、9、11），沿中轴对称：明间（当心间）最宽，往外依次是次间、梢间、尽间，宽度递减。**进深**按"架"（椽数）计。
- 宋式殿堂有 4 种标准柱网平面：单槽、双槽、分心槽、金箱斗底槽。厅堂型的内柱"随举势定其短长"[2]。
- **程序化配方**：
  - 输入：开间数 N、明间宽 w0、递减率 r（经验值 0.85–0.95）、进深架数 J、步架长 s。
  - 柱位：x_i 左右对称累加，z_j = j·s。
  - 檐柱高 h_c 由明间宽推出（小式 ≈ 0.8 w0，未核实，见 1.4），再按 1.3 加生起和侧脚。
  - 屋顶基底 = 柱网外框 + 出檐。

### 1.10 园林要素（Garden elements）

- **假山与太湖石**：太湖石是石灰岩经水长期侵蚀而成，多窝孔、穿孔，"玲珑"[31]。江南三大名石是玉玲珑（豫园）、冠云峰（留园）、绉云峰（杭州）[31]。品石常说"瘦、漏、透、皱"，一般传为米芾所提，出处**未核实**。
  - 实时：程序化可以用 SDF 噪声减去球体做孔洞，再 marching cubes 得到网格，或预先烘焙几块高模石头【局:程序化可行，但要好看仍需美术调参；材:3–5 块精修石】。
- **廊**：游廊、复廊（中间隔墙、两侧通行）、爬山廊、水廊。廊是连接空间的"路径模块"，适合样条（spline）驱动生成。
- **亭**：有屋顶、无墙或不完全封闭，供休息 [51]，多为攒尖顶。
- **榭**：临水或架于水上的平台建筑。**舫**：形似船的临水建筑（石舫、旱船）。
- **桥**：曲桥（折线平桥）、拱桥（石拱）、廊桥。
- **铺地**：花街铺地，用卵石、碎瓦拼出图案，适合贴花（decal）。
- **植物**：松、竹、梅、芭蕉、荷、垂柳，每种都有约定的位置和含义。
- **造园手法 → 相机与关卡语言**：
  - **框景**：通过门洞、窗洞取景 → 相机预设"洞门构图"，前景暗框 + 中景亮景。
  - **借景**：把园外远山、塔纳入视野 → 远景卡片（skybox impostor），对齐视线轴。
  - **对景、障景、漏景**：路径尽头设景，入口先遮挡，漏窗半透 → 关卡节奏"欲扬先抑"。
  - **移步换景**：沿路径每隔一段出现新构图 → 相机样条加构图检查点。
  - 计成《园冶》的"巧于因借，精在体宜"常被引作造园要旨（**未核实**原文出处页）。

## 2. 中国画技法与渲染映射（Painting techniques → rendering）

山水画的基本步骤是"勾、皴、擦、染、点"[39]：先用墨线勾出山石轮廓，再用各种皴法画出明暗向背，然后用淡墨渲染加强立体感，最后用浓墨或鲜明颜色点出苔点和远树 [39]。这个顺序可以直接对应成一条渲染管线：**轮廓线 → 纹理笔触 → 明暗晕染 → 点缀贴花**。

### 2.1 线：白描与十八描（Line: baimiao & the 18 line types）

**白描**只用墨线勾勒、不设色，可以略加淡墨渲染。它有单钩和复钩之分：复钩是先用淡墨钩一遍，再用浓墨局部复钩，以加强质感 [35]。线条要求"中锋为主"，压力和速度均匀，效果"外柔内刚"[35]。

**十八描**出自明代邹德中的著作。维基条目写作《绘画发蒙》、"嘉庆年间"[35]，通行说法是嘉靖年间的《绘事指蒙》，**存疑，未核实**。十八种描法是：行云流水描、高古游丝描、铁丝描、柳叶描、琴弦描、蚂蝗描、混描、橛头钉描、曹衣描、钉头鼠尾描、折芦描、减笔描、战笔水纹描、竹叶描、橄榄描、蚯蚓描、枣核描、枯柴描 [35]。

下表把常用描法翻译成"线宽沿笔画的变化函数 w(t)"（t ∈ [0,1] 为笔画起止），方便做成参数。描述是本文的归纳。

| 描法 | 视觉特征 | w(t) / 参数化 | 典型题材 |
|---|---|---|---|
| 高古游丝描 | 极细、均匀、连绵，像游丝 | w 恒定且很细，曲率平滑 | 顾恺之式仕女（《洛神赋图》宋摹，故宫） |
| 铁线描 | 均匀，比游丝略粗，挺劲 | w 恒定、中等，转角不圆滑 | 宗教人物、衣纹 |
| 琴弦描 | 长直、均匀，像琴弦 | w 恒定，曲率低 | 长衣纹 |
| 行云流水描 | 流畅回旋 | w 轻微正弦起伏 | 飘带 |
| 柳叶描 | 两头尖、中间粗 | w = sin(πt) | 衣纹、花叶 |
| 枣核描 / 橄榄描 | 两头尖、中段鼓起，比柳叶描更短更胖 | w = sin(πt)^0.5 | 短褶 |
| 钉头鼠尾描 | 起笔重如钉头，收笔细如鼠尾 | w = (1−t)^1.5，起点加重点 | 衣纹 |
| 蚂蝗描 | 粗细交替起伏，像蚂蝗爬行 | w = 1 + 0.5 sin(6πt) | 衣纹 |
| 折芦描 | 折角锐利，像折断的芦苇 | 分段直线，折点加粗 | 粗布衣 |
| 战笔水纹描 | 颤动的线 | 法向抖动噪声，振幅约 0.3w | 水纹、老人衣纹 |
| 枯柴描 / 减笔描 | 粗放、飞白多 | w 大，加飞白阈值噪声 | 写意人物 |
| 混描 | 淡墨打底，浓墨复勾 | 两遍描边，偏移叠加 | — |

**实时实现**：
- 后处理描边（Sobel 边缘检测，或深度加法线边缘）只能给出均匀线【实】，做不出 w(t)。
- 要有笔触感，得提取轮廓或折痕边线（silhouette/crease edges）生成线网格，沿边线参数 t 套 w(t)，再贴笔刷纹理（brush stroke texture）【局:需要边线提取与连接，Three.js 可以用 `LineSegments2` 加自定义宽度属性；材:3–5 张笔刷纹理】。
- 退一步的做法：屏幕空间描边 + 噪声扰动宽度 + 端点淡出，能做出"有手感"但不精确的线【实】。

### 2.2 皴法（Cun: texture strokes）

皴法用来表现山石的质地和明暗向背。下表的画家对应主要来自 [39] 的作品注释与 [41][42]，视觉描述是本文的归纳。

| 皴法 | 代表画家 / 作品 | 视觉描述 | 适合的地貌 | 实时近似方案 | 可实现度 |
|---|---|---|---|---|---|
| **披麻皴** hemp-fiber | 董源、巨然，黄公望《富春山居图》 | 长而柔的平行线，像散开的麻缕，顺山坡向下，线间有淡墨染 | 江南土山，圆浑丘陵 | 三平面投影（triplanar）贴长条笔触纹理，方向对齐坡度下降方向（梯度），密度跟随明暗 | 【实；材:披麻笔触贴图】 |
| **雨点皴**（芝麻皴）raindrop | 范宽《溪山行旅图》[39] | 密集、略竖的短点，像雨打在石面上 | 北方巨岩正面 | 泊松盘（Poisson-disk）短竖点，用明暗调密度（类似色调艺术贴图 Tonal Art Maps） | 【实】 |
| **卷云皴**（云头皴、鬼面皴）cloud | 郭熙《早春图》[39] | 回旋卷曲的笔触，像翻涌的云，山体有扭动感 | 北方主峰、云雾山 | 曲率驱动的弧形笔触；或用旋涡噪声（curl noise）扭曲 UV 后贴笔触 | 【局:效果依赖调参】 |
| **斧劈皴**（大/小）axe-cut | 李唐（小斧劈）[39]、马远、夏珪（大斧劈）；[42] 称李唐完善了 axe-cut 笔法 | 侧锋斜劈，三角形块面，干硬锐利，像斧凿 | 坚硬岩壁、断崖 | 硬阶梯色阶（2–3 阶）加平笔刷贴图，沿屏幕空间法线方向；块面化建模（low-poly 硬边）本身就像斧劈 | 【实】 |
| **解索皴** untwisted rope | 赵孟頫《鹊华秋色》[39]、王蒙 | 波状弯曲长线，像解开的绳索 | 土石混合的山 | 正弦扰动的披麻纹理 | 【实；材:笔触贴图】 |
| **牛毛皴** ox-hair | 王蒙《青卞隐居图》 | 极密、极细的短线，层层交织 | 繁密山体 | 高频交叉排线（cross-hatching）贴图，按距离做 LOD，否则远处会闪烁（aliasing） | 【局:远景摩尔纹】 |
| **米点皴**（米家云山）Mi dots | 米芾、米友仁（《潇湘奇观图》《云山图》）；[41] 描述为用平笔蘸湿墨打出的宽点 | 横向排列的湿墨大点，层层叠加，边缘洇开 | 雨后、烟雨中的江南丘陵 | 在地形上散布横向椭圆贴花，越高越淡；配合高度雾。这是最适合实时的一种皴法 | 【实】 |
| **折带皴** folded-ribbon | 倪瓒《容膝斋图》《渔庄秋霁图》 | 横向起笔再折向下，像折叠的带子，干笔淡墨 | 太湖边平坡、层状岩 | 地形按高度分层（terracing）加 L 形笔触 | 【实】 |
| **荷叶皴**、**马牙皴**、**乱柴皴**、**豆瓣皴**、**拖泥带水皴** | 各家 | 荷叶筋脉状；马牙状方折（多见于早期青绿）；乱柴交叉；豆瓣短点；湿笔带水 | — | 都可以归结为"笔触形状 × 方向场 × 密度"三元组 | 【局】 |

**通用实现思路**：把每种皴法参数化为 `{strokeTexture, directionField: 'slope' | 'curvature' | 'screen', density: f(shade), wetness, jitter}`，在 shader 里用明暗值（N·L 加 AO）驱动笔触密度和覆盖率，再和纸张底色做正片叠底。手工资产需求最少是每种皴法 1 张 512² 的灰度笔触瓦片（可以在 tileable 纹理里手绘或程序生成）。

### 2.3 设色方法（Coloring methods）

| 方法 | 含义 | 渲染对应 | 可实现度 |
|---|---|---|---|
| **平涂** flat | 色块均匀填满 | 无光照的纯色材质（Unlit） | 【实】 |
| **勾填**（勾勒填彩）outline-and-fill | 先勾墨线，再在线内填色 | 描边 + 平涂或二阶卡通着色（cel） | 【实】 |
| **分染** graded wash | 用一支色笔、一支清水笔，从结构深处向外把颜色晕开，形成单向渐变 | 物体局部渐变：用 AO、凹度（cavity）或"到轮廓的距离"驱动颜色由深到浅 | 【实：用 AO、凹度贴图或顶点色】 |
| **罩染** overall glaze | 在分染好的底上，整体薄罩一层透明色 | 全局或分材质的正片叠底色层，或 LUT 调色 | 【实】 |
| **接染** blended wash | 两种颜色在湿润时相接、自然过渡（如花瓣尖红、根白） | 两色沿物体局部轴向渐变（UV 或顶点色），过渡区加噪声 | 【实】 |
| **没骨** boneless | 不用墨线勾轮廓，直接用色或墨画出形体。黄筌的花轮廓线细到上色后几乎看不出，称"没骨花枝"；北宋徐崇嗣只用色彩，称"没骨图"[36] | 关闭描边，用柔边色块加湿边（wet edge）表现形体 | 【实】 |
| **烘染、积色** | 用背景色衬托主体（烘云托月），多次叠色加深 | 背景渐晕（vignette）、主体周边留白光晕 | 【实】 |
| **叠晕**（宋代彩画）| 同一色相由浅到深分 3–4 级色带 | 色阶贴图（ramp texture）的阶梯 | 【实】 |

### 2.5 构图：三远、留白、四时、三大

**三远**（郭熙《林泉高致》原文 [40]）："山有三远：自山下而仰山巅，谓之高远；自山前而窥山后，谓之深远；自近山而望远山，谓之平远。高远之色清明，深远之色重晦，平远之色有明有晦；高远之势突兀，深远之意重叠，平远之意冲融而缥缥缈缈。"

| 三远 | 视点（相机） | 色彩、雾 | 代表 | 相机预设（经验值） |
|---|---|---|---|---|
| **高远** | 山脚仰望山巅 | "清明"：对比高、雾少 | 溪山行旅图（[39] 称其为全景式高远构图）| 竖幅（9:16 或卷轴比例），相机低位，俯仰角 +10° 至 +25°，FOV 35–45°，主峰占画面高度 60% 以上 |
| **深远** | 从山前窥山后，层层叠嶂 | "重晦"：层次多、整体偏暗 | 早春图 | 高机位，俯角 −15° 至 −30°，FOV 40–55°，前中远景 3–5 层，层间加雾带 |
| **平远** | 从近山望远山，视线水平 | "有明有晦，冲融缥缈" | 富春山居图、鹊华秋色、容膝斋图（一河两岸）| 横幅宽画面（21:9 至卷轴），俯仰约 0°，长焦（FOV 20–30°）或接近正交，以水平分层为主 |

- **"三大"**：山大于木，木大于人 [40]。这是一条尺度规则：画中人物极小，用来衬托山的体量。游戏里可以把它当作"角色占屏比例上限"或"地标尺度"预设。
- **四时**：烟岚"春山淡冶而如笑，夏山苍翠而如滴，秋山明净而如妆，冬山惨淡而如睡"；云气"春融，夏蓊郁，秋疏薄，冬黯淡"[40]。可以直接做成 4 套季节预设：雾浓度、饱和度、对比度、云层覆盖。
- **可行、可望、可游、可居** [40]：好的山水要让人想进去走、去住。这句话可以当作场景设计的检验标准：有路、有屋、有人迹。
- **留白**（余白、布白）：刻意保留的空白，是有安排的"虚" [54]；纸或绢的空白直接当作天、水、云、雾（计白当黑）。实现上用高度雾或距离雾，雾色等于纸色，而不是灰蓝色；画面边缘做纸色暗角，并压低远景的细节和对比度【实】。
- **边角之景**（"马一角、夏半边"）：马远、夏珪的南宋小品常把主体压在画面一角，其余大片留白（月下赏梅图、溪山清远）。可以做成三分法加对角留白的构图辅助线。
- **散点透视与长卷**：手卷靠横向展开、移步换景（清明上河图、千里江山图），不是单一灭点。可以用横向卷动的相机加分段视差，或让每段使用不同的局部相机，再用雾带拼接【局:多相机拼接需要定制】。

### 2.6 墨分五色（Five tones of ink）

- 唐代张彦远《历代名画记》有"运墨而五色具"之说（常见引述，**未核实**原文卷次）。今天通行把墨色分为**焦、浓、重、淡、清**五级（出处多样，**未核实**）。
- 郭熙也列出了运墨的种类：淡墨、浓墨、焦墨、宿墨、退墨、厨中埃墨，以及青黛杂墨水；并说"用淡墨六七加而成深，即墨色滋润而不枯燥"[40]。后一句说的是**多层淡墨叠加**比一次重墨更润，对应渲染里的多层半透明叠加（multi-pass glaze），而不是单层不透明色。
- 再加上**干、湿**两个维度（干笔飞白、湿笔洇散），就构成水墨渲染的参数空间：

| 参数 | 含义 | 实现 |
|---|---|---|
| tone（焦→清 5–6 级）| 明度台阶 | 色阶贴图或量化 N·L；对应色组 `cn-shuimo` |
| wetness 湿度 | 边缘洇散、晕开 | 屏幕空间模糊加边缘加深（wet-edge darkening，水彩渲染常用）【实】 |
| dryness 干笔/飞白 | 笔触中断、露白 | 噪声阈值遮罩，沿笔触方向拉伸【实】 |
| granulation 颗粒 | 墨或颜料在纸纹中沉积 | 纸纹高度贴图乘浓度【实；材:纸纹】 |
| bleeding 渗化 | 宣纸的洇 | 降采样后各向异性扩散，或几帧时间累积【局:性能敏感】 |
| paper 底材 | 绢（经纬织纹、老化偏褐）/ 纸（纤维）| 底纹贴图加色调【材:绢纹、宣纸纹】 |

### 2.7 装裱、印章与题跋（作为 UI 与画面元素）

- **装裱**（手卷、立轴、册页、团扇）可以直接用作画框和 UI 容器。手卷对应横向卷动的视口，团扇对应圆形视口（马远月下赏梅图就是团扇改装的册页）。
- **印章**：朱文（红字）、白文（红底白字），印泥色见 `cn-shuimo` 的高粱红。位置一般在画面边角，不压主体。生成时要避免伪造真实收藏印或名家印，用原创印文。
- **题跋**：书法文字块，用作标题或剧情文本。字体需要有授权的书法字体。

## 4. 避免混搭：和风、韩式与中式（Japanese / Korean distinctions）

做"中式"场景时，最常见的错误是混进日式元素，其次是韩式。下表列出识别要点。"日式""韩式"两列的内容大多是常识归纳，标注来源的除外。

| 维度 | 中式（以明清官式与江南为参照） | 和风（日本传统） | 韩式（韩屋 Hanok、丹青 Dancheong） |
|---|---|---|---|
| 屋顶名称对应 | 庑殿、歇山、悬山、攒尖 | 寄棟造、入母屋造、切妻造、宝形造（[7][8][9][11] 的日文名）| 우진각（庑殿）、팔작（八作，即歇山）[7][8] |
| 屋顶曲线 | 屋面凹曲；北方翼角含蓄，江南、闽粤高翘；正脊常有吻兽、走兽 | 檐口线较平直、出檐很深；寺社屋顶常用桧皮葺（`jp-jinja` 的檜皮）、铜板葺（緑青色）；少用琉璃瓦 | 正脊两端上扬，整条檐线是柔和的连续曲线；宫殿垂脊上有雑像（잡상）|
| 木构颜色 | 朱红柱、青绿彩画；江南为栗色木 | 素木（白木）或丹涂（朱漆），少有满铺彩画 | **丹青**：以绿色为底，上面绘对比色图案（朝鲜王朝以来）[44] |
| 装饰彩画 | 和玺、旋子、苏式，三段式构图，大量用金（宫廷）| 极简，或桃山、江户时期的金箔障壁画（室内）| 丹青以五方色为基础（青东、白西、赤南、黑北、黄中）[44]；纹样分모루초（梁头）、별지화、비단무늬（锦纹）、단독무늬 四类 [44]。"丹青"一词与中文同源 [44] |
| 墙与开口 | 白墙或灰砖墙，漏窗、月洞门、隔扇（糊纸或玻璃）| 障子（糊纸推拉门）、襖、榻榻米、缘侧（外廊）| 窗户纸（창호지）、地暖（온돌）抬高的地面、木地板大厅（대청）[46] |
| 庭园 | 以水为心，太湖石（多孔、竖立、堆叠成山）、廊、亭、漏窗，"可游可居" | 枯山水（白砂耙纹加石组），苔庭，石组多实心、平卧 [45] | 自然式，较少人工堆山，常有方池圆岛 |
| 门 | 牌坊、垂花门、影壁 | 鸟居（神社）、山门 | 홍살문（红箭门）、一柱门 |
| 典型配色 | 红墙黄瓦（皇家）、粉墙黛瓦（江南）| 朱（鉛丹）、素木、桧皮褐、苔绿 | 绿底丹青 + 红柱 + 灰瓦 |

**避坑清单**
- 鸟居、石灯笼（日式比例）、枯山水耙纹、榻榻米、障子格子不要出现在中式场景里。
- 中式隔扇的棂格密而繁复，日式障子是简洁的方格大纸面。
- 用色上，绿底满铺的梁枋彩画偏韩式丹青；中式官式彩画讲究青绿相间（同一构件上蓝绿交替）并贴金。
- "汉服 + 和风建筑"或"中式屋顶 + 樱花鸟居"是常见的文化误植，评审时要逐项检查。

## 5. 给探索台的落地建议

1. **模块化建筑 kit（第一批）**：
   - 台基（普通、须弥座）
   - 柱与额枋
   - 斗拱 LOD 阶梯
   - 隔扇、槛窗、漏窗、月洞门
   - 屋顶生成器（7 种类型，加重檐、卷棚开关）
   - 脊与吻兽
   - 马头墙段
   - 游廊（样条驱动）
   - 亭（4、6、8 角，圆形）
   - 曲桥、拱桥
   - 影壁、垂花门
   - 太湖石 3–5 块
2. **参数面板**（示意）：

## 未核实清单（汇总）

- **清式数据**：举架的具体举数序列（五举到九举）、"冲三翘四"、小式明间面阔与柱高比 10:8、柱径为柱高的 1/11、台明高为檐柱高的 1/5、斗口分 11 等。都是常见引述，没有对照梁思成《清式营造则例》原书。
- **江南发戗**：《营造法原》中嫩戗、水戗发戗的数值。
- **"瘦漏透皱"**归于米芾；《园冶》"巧于因借，精在体宜"的具体出处页。
- **门钉、屋瓦颜色、脊兽数量**的等级规制细节（宫门门钉 9×9、太和殿走兽 10 个、绿琉璃用于王府和寺庙）。
- **十八描出处**：维基条目写作邹德中《绘画发蒙》、嘉庆年间，与通行的《绘事指蒙》、嘉靖之说不一致。
- **墨分五色**：张彦远"运墨而五色具"的卷次；"焦浓重淡清"五分法的出处。
- **游戏案例**：《绘真·妙笔千山》《江南百景图》等的技术细节。
- **日韩对照表**：未标注来源的条目是常识归纳。
- **博物馆**：辽博 3 件、Nelson-Atkins 1 件、夏永《黄鹤楼图》，以及 MFA 下载授权条款。
- **满洲窗彩色玻璃**作为广府民居特征。
